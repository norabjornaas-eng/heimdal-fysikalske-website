# Heimdal Fysikalske Website

A responsive website developed for Heimdal Fysikalske Institute, a physiotherapy clinic in Norway.

## Project Overview

This project was created to provide a modern and user-friendly website for a physiotherapy clinic. The website presents information about services, pricing, treatments, and contact details in a clear and accessible way.

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Features

* Responsive design for desktop and mobile devices
* Clean and modern user interface
* Service overview pages
* Pricing section
* Contact information
* Easy navigation

## My Role

I designed and developed the website structure, layout, and user interface while focusing on responsiveness and user experience.

## What I Learned

Through this project, I improved my skills in:

* HTML and semantic structure
* CSS styling and responsive design
* JavaScript fundamentals
* Web development best practices
* Creating real-world websites for clients

## Future Improvements

* Online booking functionality
* Contact form integration
* Improved accessibility
* Additional language support
